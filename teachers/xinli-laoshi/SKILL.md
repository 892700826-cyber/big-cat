# 内在咨询师：心理矛盾自助分析流程

> 当你内心拉扯、情绪翻涌时，用专业视角温柔陪伴自己

## 使用说明
- 找一个安静角落，准备纸笔
- 跟随以下5步，用15–30分钟完成自我对话
- 不求"立刻解决"，只求"更理解自己一点"

---

## 第一步：命名矛盾（Stop & Label）

问自己：
**"此刻我内心在 哪两股力量之间拉扯？"**

常见类型：
- **理性 vs 情感**："知道该放下，但舍不得"
- **责任 vs 自我**："想休息，又怕辜负期待"
- **安全 vs 成长**："想改变，又怕失败"
- **独立 vs 依赖**："渴望亲密，又怕被控制"

**行动：** 在纸上写下：
```
我的矛盾是：______ vs ______
```

---

## 第二步：深度倾听自己（用参与性技术）

像咨询师一样，不评判，只倾听：

自问：
- "这种拉扯，主要带来什么情绪？是焦虑？委屈？恐惧？"
- "你说'压力大'，具体是指哪件事？哪个场景最难受？"
- "听起来，你既想要A，又害怕失去B，对吗？"

**行动：** 写下：
```
我真正的情绪是：________________
最让我卡住的具体事件是：________________
```

---

## 第三步：探索背后的需求（个案概念化）

从三个视角看自己：

**人本视角**
问："如果完全接纳自己，我会允许自己要什么？"
→ 发现真实需求

**CBT视角**
问："我脑中反复出现的自动思维是什么？（如'我不够好''选错就完了'）"
→ 识别认知扭曲

**系统视角**
问："这个选择，会如何影响我重要的人？他们期待我怎样？"
→ 看见关系中的隐形绳索

**行动：** 分三栏简要回答：
```
[人本] 我真正想要的是：________
[CBT] 我的自动思维是：________
[系统] 他人对我的期待是：________
```

---

## 第四步：寻找第三选择（超越非此即彼）

打破"只有两个选项"的错觉：

问自己：
- "有没有一种方式，部分满足A，也部分照顾B？"
- "如果暂时不做决定，我能先做什么小行动？"

破局思路参考：
- **时间维度**："现在做X，3个月后评估是否继续"
- **程度维度**："不全职追梦，但每周投入5小时试水"
- **角色分离**："作为子女要负责，但作为自己也要喘息"

**行动：** 写下1–2个"第三选择"方案：
```
我可以：________________________
```

---

## 第五步：自我共情与承诺

对自己说（像对最好的朋友）：
> "你处在这样的矛盾中，已经很不容易了。
> 不需要立刻完美解决，
> 只要今天比昨天更理解自己一点，就是进步。"

然后，做一个微小但确定的承诺：
**接下来24小时，我会为自己做一件小事：** ________________
（例：允许自己哭10分钟 / 给信任的朋友发一句"我有点累" / 推迟重大决定，先睡一觉）

---

## 完整模板

```
【我的心理矛盾】
______ vs ______

【我的真实情绪】

【最卡住的具体点】

【三方视角】
[人本] 我真正想要的是：________
[CBT] 我的自动思维是：________
[系统] 他人对我的期待是：________

【第三选择】
我可以：________________________

【对自己的温柔承诺】
接下来24小时，我会：________________
```

---

## 结语

当一个人被深深理解，改变就会自然发生。
而你，值得成为那个理解自己的人。
